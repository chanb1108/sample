이미지 미리보기
  • 설명
    • X-Free Uploader는 이미지 파일에 한해서 썸네일 표현 뿐만 아니라 미리보기 팝업을 제공합니다.
  • 이미지 미리보기 팝업 실행 방법
    • 1) 이미지파일 항목 더블클릭
    • 2) 이미지파일 항목 체크선택 후 우측 컨텍스트 메뉴의 [선택된 이미지 미리보기] 항목 클릭
    • 3) 이미지파일 항목 체크선택 후 XFU커스텀버튼의 [이미지미리보기]버튼 클릭 (showImageViewer함수 사용)
  • ※ 이미지 파일크기가 일정 이상 고용량(현재 10MB 설정 기준)인 경우에는 Read속도가 오래걸려 이미지 미리보기 팝업에서는 기본이미지로 대체하고 브라우저 새창 열기로 대체하여 미리보기 제공합니다.
