iframe에 적용 방법
  • 설명
    • 웹페이지에서 X-Free Uploader의 구성은 body태그 안에 div태그 추가하고 id와 class를 적용하여 세팅하는 걸 권장하나 경우에 따라 웹페이지에 iframe을 감싸서 사용하는 사례가 있습니다.
    • 일반적인 웹페이지에 X-Free Uploader를 적용시 문제는 없으나 웹페이지 안에 iframe을 감싸서 X-Free Uploader를 넣고 사용해야하는 경우에는 팝업 창의 위치정보를 위해 아래와 같이 옵션 값을 적용해야 합니다.
    • iframe 태그 안에 data-xfuID라는 속성을 추가하고 render값이 선언된 태그의 ID값(예 : "fileUpload")을 명시합니다.
    • 예 시
    • ※ iframe 태그 안에 data-xfuID라는 속성을 추가하지 않고 실행시 팝업 창은 iframe 내부에 종속되어 잘려보일 수 있습니다.
    • 해당 페이지의 소스를 참고하시면 [파일전송]버튼은 해당 웹페이지의 태그입니다. 자세한 정보는 해당 페이지 소스를 참고하시기 바랍니다.
