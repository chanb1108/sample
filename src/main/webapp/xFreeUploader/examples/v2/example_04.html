▷ 커스텀 버튼 추가

1) 버튼명 및 표현메시지내용 입력

X-Free Uploader 내부 영역에 추가할 커스텀버튼의 정보를 입력합니다.

2) 버튼추가 실행

해당 버튼을 누르면 X-Free Uploader 내부 영역에 커스텀버튼이 추가됩니다.

3) 버튼클릭이벤트 실행결과

추가된 커스텀버튼을 클릭시 해당영역에 메시지가 출력되도록 하여 해당 커스텀버튼의 흐름을 파악할 수 있습니다.
